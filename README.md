# 🏫 سامانه هوشمند مدیریت کلاس درس، آزمون‌ساز و حضور و غیاب دانش‌آموزان
### Smart Classroom Attendance, Assessment & Supabase Cloud Integration (Version 4.3.0)

این سامانه یک وب‌اپلیکیشن کامل، مدرن و ریسپانسیو مبتنی بر **React**، **TypeScript**، **Tailwind CSS** و پایگاه‌داده ابری **Supabase (PostgreSQL)** است که به صورت ویژه برای مدارس، دبیران و دانش‌آموزان ایرانی با تقویم جلالی، تایم‌زون تهران و امکان اتصال به پیام‌رسان **ایتا (Eitaa)** طراحی شده است.

---

## ✨ ویژگی‌های برجسته سامانه

1. **پایگاه‌داده ابری Supabase (PostgreSQL) با تایم‌زون ایران (`Asia/Tehran`):**
   - ذخیره و همگام‌سازی لحظه‌ای دانش‌آموزان، حضور و غیاب، تکالیف و نمرات آزمون‌ها
   - پشتیبانی موازی از حافظه محلی (Fallback به LocalStorage در صورت عدم تنظیم کلیدها)
   - امنیت داده‌ها با Row Level Security (RLS) و اسکریپت آماده `supabase-schema.sql`

2. **اتصال اختصاصی به گروه‌های چت ایتا به تفکیک درس و کلاس:**
   - امکان تعریف لینک گروه چت ایتا برای هر درس و کلاس
   - هدایت خودکار دانش‌آموزان پس از ثبت حضور به گروه چت همان درس

3. **مدیریت کلاس پیشرفته (Class Management):**
   - افزودن انفرادی یا گروهی دانش‌آموزان با اطلاعات سیدا (کد ملی، نام پدر، شماره تماس)
   - جستجوی سریع، گروه‌بندی، انتقال و خروجی گزارش‌ها

4. **سیستم آزمون‌ساز کلاسی پیشرفته:**
   - **آزمون‌های تستی:** سوالات چهارگزینه‌ای با تایمر معکوس و تصحیح و نمره‌دهی خودکار
   - **آزمون‌های تشریحی:** ارسال سوال همراه تصویر، دریافت پاسخ و ثبت بازخورد دبیر

5. **پنل مدیریت و کاربری دبیران (رمز پیش‌فرض مدیر: `1234`):**
   - مدیریت رمزهای عبور و دسترسی اختصاصی به تفکیک هر دبیر
   - گردونه تصادفی پاسخ‌دهی، تایمر کلاسی، سوابق حضور و غیاب و نمودارهای ارزیابی

## 🚀 راهنمای انتقال به گیت‌هاب (GitHub) و استقرار خودکار

این پروژه به طور کامل برای استقرار در **GitHub Pages**، **Vercel** و **Netlify** آماده‌سازی شده است.

### روش اول: خروجی مستقیم از محیط AI Studio (ساده‌ترین روش)
1. در بالای صفحه AI Studio، روی علامت منو (سه‌نقطه یا چرخ‌دنده تنظیمات) کلیک کنید.
2. گزینه **Export to GitHub** را انتخاب کنید.
3. مخزن (Repository) جدید را در حساب گیت‌هاب خود انتخاب یا ایجاد نمایید. پروژه با تمام فایل‌ها مستقیماً منتقل می‌شود.

---

### روش دوم: بارگذاری دستی با Git

اگر فایل‌های پروژه را دانلود کرده‌اید یا از طریق ترمینال کار می‌کنید:

```bash
# رفتن به پوشه پروژه
cd classroom-manager

# مقداردهی اولیه گیت (در صورت نیاز)
git init
git add .
git commit -m "feat: initial commit - classroom manager ready for production"

# متصل کردن مخزن گیت‌هاب خود
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY_NAME.git
git branch -M main

# ارسال به گیت‌هاب
git push -u origin main
```

### 🌐 فعال‌سازی استقرار رایگان در GitHub Pages

در پوشه `.github/workflows/deploy.yml` تنظیمات اجرای خودکار تعبیه شده است:

1. در مخزن گیت‌هاب خود وارد تب **Settings** شوید.
2. از منوی سمت چپ به بخش **Pages** بروید.
3. در زیر عنوان **Build and deployment**، گزینه **Source** را روی **GitHub Actions** قرار دهید.
4. با هر بار `git push` به شاخه `main`، سایت شما به صورت خودکار ساخته شده و در آدرس زیر در دسترس خواهد بود:
   ```
   https://<YOUR_USERNAME>.github.io/<YOUR_REPOSITORY_NAME>/
   ```

---

### 🔑 تنظیم متغیرهای Supabase در GitHub Pages (اختیاری)

اگر می‌خواهید نسخه GitHub Pages به دیتابیس Supabase شما متصل شود:
1. در مخزن گیت‌هاب به **Settings** > **Secrets and variables** > **Actions** بروید.
2. در تب **Secrets** یا **Variables**، مقادیر زیر را اضافه کنید:
   - `VITE_SUPABASE_URL`: آدرس Project URL شما در Supabase
   - `VITE_SUPABASE_ANON_KEY`: کلید anon public شما در Supabase
3. با انتشار بعدی، بیلد GitHub به صورت متصل به Supabase اجرا خواهد شد.

---

### 🗄️ راه‌اندازی دیتابیس Supabase

1. در پنل [supabase.com](https://supabase.com) یک پروژه رایگان ایجاد کنید.
2. از منوی سمت چپ وارد بخش **SQL Editor** شوید.
3. محتویات فایل `supabase-schema.sql` (موجود در ریشه همین پروژه) را در آن کپی کرده و دکمه **RUN** را بزنید.
4. مقادیر `Project URL` و `anon public key` را دریافت کرده و در متغیرهای پروژه وارد کنید.

## 💻 نحوه اجرای محلی (Local Development)

```bash
# ۱. نصب پیش‌نیازها
npm install

# ۲. ایجاد فایل متغیرهای محیطی
cp .env.example .env

# ۳. اجرای سرور توسعه
npm run dev

# ۴. بررسی خطاهای تایپ‌اسکریپت
npm run lint

# ۵. ساخت نسخه نهایی پروداکشن
npm run build
```
